# Cyber Python Labs & Portfolio

A repository dedicated to the development of practical Python utilities for offensive/defensive security analysis (SOC) and digital forensics, in line with studies at TU Dublin.

## Module Structure

- **`01-fundamentals/`**: Conditional logic, relational operators, Boolean expressions and f-strings applied to incident triage.
- **`02-collections-loops/`**: Manipulation of lists, dictionaries and filtering/firewall rules.
- **`03-forensic-file-handling/`**: Processing log files and extracting artefacts.
- **`04-security-tooling/`**: Utilities using native libraries (`hashlib`, integrity and chain of custody).
